# Saved assistant answers

These files are answers that an AI assistant gave to a prompt, saved so
that everyone can do the verification task in the lab **without** network
access or an assistant of their own. They are kept exactly as the
assistant wrote them. Some of what they say is wrong on purpose: your job
in the lab is to find out which parts.

| File | Prompt | Used in |
|---|---|---|
| `capitalize_words.md` | "Write a Dart function `capitalizeWords` that makes the first letter of each word upper case." | Lab 1, Task 5 |
